# 📩 نظام رسائل المدرسين

نظام إشعارات فورية اتجاه واحد: مجموعة مديرين → كل المدرسين (أو مدرس معين).
كل مدرس عنده يوزر + بن كود (4 أرقام) يدخل بيهم مرة واحدة بس، وبعدها يستقبل إشعارات حقيقية على موبايله حتى لو التطبيق مقفول.

## 🧱 مما يتكون المشروع
- **Backend**: Node.js + Express + SQLite (قاعدة بيانات ملف واحد، مفيش داعي لسيرفر قاعدة بيانات منفصل)
- **Frontend**: تطبيق ويب (PWA) شغال من المتصفح، وممكن "يتضاف للشاشة الرئيسية" فيبقى شكله زي تطبيق عادي
- **الإشعارات**: Web Push (نفس تقنية إشعارات الفيسبوك/الجيميل على المتصفح) — مجانية بالكامل وبدون أي حساب Firebase أو Apple Developer

## 📁 هيكل المشروع
```
teacher-messenger/
├── server/            الباك إند (API)
├── public/            الواجهة (المدرسين + المديرين)
│   ├── index.html      صفحة المدرس
│   ├── admin.html       لوحة تحكم المديرين
│   └── sw.js            Service Worker (لاستقبال الإشعارات)
├── .env.example
└── package.json
```

## 🚀 التشغيل محليًا (للتجربة)

1. ثبّت المتطلبات (لازم Node.js نسخة 18 أو أحدث):
   ```
   npm install
   ```

2. ولّد مفاتيح الإشعارات (مرة واحدة بس):
   ```
   npm run generate-vapid
   ```
   انسخ الناتج وحطه في ملف `.env` (اعمل نسخة من `.env.example` وسمها `.env`)

3. شغّل السيرفر:
   ```
   npm start
   ```

4. افتح:
   - **واجهة المدرسين**: http://localhost:3000
   - **لوحة المديرين**: http://localhost:3000/admin.html

   أول حساب مدير بيتعمل تلقائيًا:
   - يوزر: `admin`
   - باسورد: `admin123`
   👈 **غيّره فورًا بعد أول دخول** (من قاعدة البيانات مباشرة أو أضف صفحة تغيير باسورد لاحقًا)

## 🌍 النشر على الإنترنت (عشان يشتغل على موبايلات حقيقية)

الإشعارات (Push) وميزات PWA بتتطلب **HTTPS** إجباري — متبقاش شغالة على `http://localhost` من موبايل حقيقي.
أسهل الطرق (كلها بيها باقة مجانية تكفي مدرسة كاملة):

| المنصة | ملاحظات |
|---|---|
| **Render.com** | ارفع المشروع على GitHub وربطه بـ Render، بيدّيلك رابط HTTPS جاهز مجانًا |
| **Railway.app** | نفس الفكرة، سريع جدًا في الإعداد |
| **VPS خاص بيك** (مع Nginx + Let's Encrypt) | لو عايز تحكم كامل |

بعد النشر، لازم تضيف متغيرات البيئة (VAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, JWT_SECRET) في لوحة تحكم المنصة اللي هتنشر عليها.

⚠️ **قاعدة البيانات**: SQLite بيتخزن كملف `data.sqlite` بجانب السيرفر. على المنصات المجانية زي Render، الملفات المؤقتة ممكن تتمسح عند إعادة التشغيل — لو النظام هيتستخدم فعليًا وباستمرار، فكّر في:
- تفعيل "Persistent Disk" في Render (متاح في الباقات المدفوعة الرخيصة)
- أو التحويل لقاعدة بيانات سحابية زي Postgres (Railway بيوفرها مجانًا كإضافة)

## 📱 استخدام المدرس للتطبيق
1. المدير يديله اليوزر والبن كود (بيتولدوا تلقائي من لوحة التحكم)
2. المدرس يفتح رابط الموقع من متصفح الموبايل (Chrome على أندرويد أو Safari على آيفون)
3. يسجل دخول مرة واحدة باليوزر والبن كود
4. المتصفح هيسأله "تسمح بالإشعارات؟" → يوافق
5. (اختياري لكن مفيد) يضيف الصفحة للشاشة الرئيسية عشان تفتح زي تطبيق عادي:
   - أندرويد: قائمة المتصفح ⋮ → "إضافة إلى الشاشة الرئيسية"
   - آيفون: زر المشاركة 📤 → "إضافة إلى الشاشة الرئيسية"

بعد كده، أي رسالة يبعتها المدير هتوصله كإشعار فوري على الموبايل حتى لو قافل المتصفح.

## 🔑 كيف يعمل تسجيل الدخول "مرة واحدة"
بعد أول دخول، بيتخزن توكن دخول (JWT) صالح لمدة سنة كاملة جوه المتصفح. المدرس مش هيحتاج يدخل اليوزر والبن كود تاني إلا لو:
- مسح بيانات المتصفح يدويًا
- المدير عمل له "إعادة تعيين بن كود" من اللوحة

## 🛠️ أهم نقاط الـ API
| Method | Endpoint | الوظيفة |
|---|---|---|
| POST | `/api/admin/login` | دخول مدير |
| POST | `/api/admin/teachers` | إنشاء مدرس (يرجع يوزر+بن كود) |
| GET | `/api/admin/teachers` | قائمة المدرسين |
| POST | `/api/admin/teachers/:id/reset-pin` | إعادة تعيين بن كود |
| POST | `/api/admin/messages` | إرسال رسالة (للكل أو لمدرس محدد) |
| POST | `/api/teacher/login` | دخول مدرس (يوزر+بن كود) |
| POST | `/api/teacher/subscribe` | حفظ اشتراك الإشعارات |
| GET | `/api/teacher/messages` | رسائل المدرس |

## 🔒 أمان لازم تراعيه قبل الاستخدام الفعلي
- غيّر `JWT_SECRET` في `.env` لنص عشوائي طويل
- غيّر باسورد حساب `admin` الافتراضي فورًا
- لو هيبقى فيه أكتر من مدير، ضيف endpoint لإنشاء مديرين جدد (حاليًا في مدير واحد بس بيتعمل أوتوماتيك أول مرة)
- شغّل الموقع على HTTPS دايمًا في الإنتاج

## 💡 تطويرات ممكن تضيفها لاحقًا
- صفحة لتغيير باسورد المدير من الواجهة
- دعم أكتر من مدير بصلاحيات مختلفة
- تصنيف المدرسين في مجموعات (مثلاً حسب المرحلة الدراسية) وإرسال لمجموعة معينة
- سجل "تم القراءة / لسه" لكل رسالة تفصيليًا لكل مدرس
